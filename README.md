# Campus Canteen Website

## Project Overview
Campus Canteen is a responsive React web application that allows students to explore food items, search the menu, filter items by category, mark favourites, view item details, and manage their shopping cart.

## Features
- Responsive layout for desktop, tablet, and mobile screens
- Food menu loaded from a local JSON file
- Search food items by name
- Filter items by category
- Add and remove favourite items
- View individual food item details
- Add items to the cart and remove them
- Display cart item count and total price
- React Router for page navigation
- Context API for shared cart state
- Loading and error messages while fetching menu data

## Technologies Used
- React
- JavaScript
- HTML
- CSS
- React Router
- Context API
- JSON

## How to Run the Project
1. Install Node.js and npm.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL displayed in the terminal.

## Data Source
Food items are stored in `public/menu.json`. Food images are loaded using online image URLs.

## Project Purpose
This project demonstrates React components, props, state management, API-style data fetching, routing, responsive design, and shopping cart functionality.
